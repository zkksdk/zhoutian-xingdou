# 周天星斗大阵（工程化拆分版）

由一个 78KB 的单文件 HTML 拆成的标准前端工程：**视觉逻辑一行未改**，只做了「搬家 + 模块化」，
之后叠加了移动端可用的交互、自适应画质与过曝压制。

> 线上：**https://zkksdk.github.io/zhoutian-xingdou/**

## 展开动画（创世序列）

打开页面会先播一段 20~24 秒的展开动画（移动端自动压缩到 16 秒），从混沌虚无一路演到周天轰鸣：

| 阶段 | 设计时刻 | 内容 |
|---|---|---|
| ① 混沌初开 | 0–2.5s | 全黑、极强暗角、中心一点灵光、相机从 dist 260 缓慢推进 |
| ② 双核诞生 | 2.5–6s | 太阳星凝聚 → 0.8 秒后太阴星转出 → 能量纽带拉丝连接 → 首次小扫描波 |
| ③ 紫微垣 | 6–9s | 星位按半径由内向外弹入（smoothstep + 过冲）、星轨连线像蛛丝生长、旋转从 0 加速 |
| ④ 太微·天市 | 9–13s | 三垣以不同速度反向旋转、14800 颗副星辰 3 秒淡入、流光由内向外点亮、符文隐现 |
| ⑤ 四象显形 | 13–17s | 二十八宿铺开 → 青龙/朱雀/白虎/玄武 每 0.8 秒依次显形，各伴随一圈局部扫描波 |
| ⑥ 北斗定枢 | 17–20s | 七颗星依次点亮留拖尾、星链连珠、摇光射出金色光柱、相机快速绕行 0.4 弧度 |
| ⑦ 周天轰鸣 | 20–24s | 内慢外快加速旋转、粗扫描波从 0 扩到 85 扫过全阵、亮度回落，交还随机事件系统 |

**实现要点**

- 全部效果由单一进度变量驱动：`intro.t`（秒）→ `tp = t × 24/播放时长`，
  各阶段用 `smoothstep` / `easeInOutCubic` / `backOut` 切分（见 `js/22-intro.js` 顶部的 `CAM` / `SCANS` / `REVEAL` 表）。
- 星位"生长"是**在顶点着色器里按半径做**的（`uReveal` 揭示半径），不是逐个对象动画 —— 一次 uniform 更新驱动上千颗星。
- 连线生长用 `uGrow` 门控 `aT` 参数（沿线段爬行）；流光用 `uGrowR` 按半径点亮。
- 防过曝（对应规格的亮度约束）：核心亮度上限 `1.1 + min(uFlash,1.0)*0.8`、光晕 Sprite 展开期不超过正常尺寸 50%、
  泛光峰值 0.7 且立即回落、后处理末尾保留 Reinhard 高光压制。
- 展开期**随机事件全部停摆**（周天扫描 / 神兽降临 / 三垣共鸣 / 日月同辉 / 星河倒灌 / 流星），
  结束后统一清零计时器，无缝交还（见 `20-main-loop.js` 里成组的 `!intro.active` 门控）。
- **跳过**：右下角「跳过 ▸」按钮或 `Esc`。

**调试开关**

| 参数 | 作用 |
|---|---|
| `?nointro=1` | 跳过展开，直接进入稳定运转 |
| `?dbg=1` | 显示 FPS/画质面板，并挂载 `__introDbg()`（读展开进度）、`__introSeek(秒)`（快进到展开某一秒） |

## 自适应画质

主循环会统计实时帧率，**低于 34 FPS 持续两秒**就自动降级：

1. 第 1 级：关闭全屏辉光（UnrealBloom 要跑 5 级模糊，是最贵的一项）
2. 第 2 级：像素比降到 1.0

切到后台会停止排帧，回到前台自动恢复（省电、防过热）。

## 依赖

three.js **已本地化到 `vendor/`**（r160，min 版约 655KB），不依赖任何 CDN。
想升级版本：替换 `vendor/three/three.module.js` 与 `vendor/three/addons/` 下的 4 个 pass 插件及其依赖
（`Pass.js` / `MaskPass.js` / `shaders/CopyShader.js` / `shaders/LuminosityHighPassShader.js`）。

## 运行

模块 + importmap 需要 HTTP 环境（`file://` 会被 CORS 拦）：

```bash
cd zhoutian-xingdou
python3 -m http.server 8080      # 或 npx serve .
# 浏览器打开 http://localhost:8080/
```

## 排查

- 页面顶部出现**红色横幅**：里面会直接写清失败原因（WebGL 不支持 / 模块加载失败 / 运行错误）。
- 控制台敲 `__errs` 可以看到收集到的全部错误。
- `_diagnose.html` 是独立的渲染自检页，逐项检测 WebGL2 / GPU / half-float / 着色器 / 模块加载。

## 改动记录

- **拆分**：22 个分节 → 独立 ES 模块（依赖单向，前向 import 末尾 export；`infActive`/`infTimer` 用 `infState` 访问器桥接）。
- **过曝压制**：Bloom 强度/半径/阈值下调；日月本体加 `min(uFlash,1.0)` 上限；光晕 Sprite 缩小；过载亮度 `1.4→0.4`；
  后处理末尾加 Reinhard 高光压制。实测白爆像素占比 47.7% → 10.3%。
- **移动端交互**：双指捏合缩放、双击复位、点按选中星位（原来手机既不能缩放也看不到星名）。
- **性能**：悬停检测由「每帧 365 次投影」改为「隔 3 帧搜索 + 每帧只算选中星位」；新增自适应降级与后台暂停。
- **健壮性**：three.js 本地化；页面内错误横幅；真实首帧后才撤掉「布阵中」遮罩。
